# Mixamo assets for Practice 1

Put the two downloaded FBX files in this folder:

- X Bot.fbx: choose X Bot in Mixamo and download the character with skin.
- Swing Dancing.fbx: choose the Swing Dancing animation and download it without skin.

Then wait for Unity to import both files and run Tools > Week 7 > Setup Mixamo X Bot Dance.

The FBX files are intentionally not committed. Download them from https://www.mixamo.com/ using your Adobe account and follow the service's license terms.
